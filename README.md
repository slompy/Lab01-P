1. Код C# перед запуском программы проверяется абсолютно весь, в отличие от Python, который выполняет код построчно. От чего код C# находит ошибки сразу же, а Python построчно.
2. Эта команда стартует сразу две команды поочередно. Сначала запускает dotnet build, который переводит текстовой код из файлов .cs в бинарный файл, который компьютер уже и сможет прочитать. После запускает саму по себе программу, если не было ошибок в коде.
3. Папка obj/ нужна чтобы складывать туда временные файлы во время сборки, чтобы в следующий раз программа запускалась быстрее, и компиляция была быстрее тоже.
Папка bin/ нужна для финального результата компиляции.
Это не наш исходный код, это результат работы компилятора под конкретную среду. Они постоянно меняются и много весят, чтобы сохранять их.
4. git commit сохраняет "снимок" нашего кода в момент написания команды лишь локально на нашем компьютере. А вот git push уже эти сохраненные локальные коммиты может отправлять на сервер GitHub.
5. Конкатенация это механическое складывание: "Привет, " + yourName + "! Тебе" + yourAge + " лет." Это неизбежно в кашу превращается, хотя на Python я так обычно и писал.
Интерполяция это современный способ, где можно одной сплошной строкой написать и текст, и переменные, которые нужно будет лишь отделить от текста фигурными скобками. $"Привет, {yourName}! Тебе {yourAge} лет." Интерполяция лучше, её легче читать, легче написать, и работает намного быстрее.
6. Если делить целое число на такое же целое, код C# просто отбросит дробную часть. Он будет жестко возвращать int, и чтобы исправить нужно чтобы хотябы одно число было дробным, можно написать double перед переменной. 
7. Константа задается жестко и на один раз, когда переменную можно изменить сколько угодно раз прямо во время выполнения программы. Константы нужны для фундаментальных и неизменных чисел. 
8. Раньше, для вывода строчки "Hello World" нужно было писать шаблонный каркас: обьявить пространство имен, написать класс, внутри него метод. Top-level statements - эот режим (с C# 9), который позволяет писать код сразу в файле с первой же строчки, без огромного каркаса. Компилятор сам невидимо от нас достраивает всю эту структуру, а для нас код становится чистым и коротким.
